# Build Your Future

A production-style React + TypeScript + Vite career-discovery city-building game.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Included
- Landing, player setup, city style, briefing
- Quick Build / Career Challenge / Free Build
- Interactive city plots and 12 building types
- 10 city challenges with hidden scoring
- 12 career attributes and career matching
- Final city reveal and achievements
- Career Explorer
- LocalStorage resume/restart
- Responsive desktop/tablet/mobile/kiosk layout
- Reduced-motion accessibility support
- Optional lightweight UI sound
- Configuration centralized in `src/config.ts`
